## Featured project

### [LMTI Atlas](https://github.com/vuthuanphat6-byte/lmti-atlas)

A local-first project memory and safety layer for AI coding agents.

- Compiles project knowledge into an atlas and generates task-specific context.
- Provides privacy-aware preflight checks and reviewed memory and lesson workflows.
- Built around a TypeScript CLI and SQLite-backed memory, with an experimental Go core.
- **Status:** Public alpha. Interfaces may change before a stable release.

## Technologies
